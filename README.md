# zipzi — Co-founder Compatibility Matching Engine

**zipzi** is a compatibility scoring engine that matches people looking for
**co-founders and collaborators** for projects, startups, and ventures.
It is **not a job board**: the goal is to measure how well two people would
work together as partners — both as humans and as a functional team.

Given a set of user profiles, the engine evaluates every pair and produces a
ranked list of matches with a transparent, explainable breakdown of *why*
each pair matches.

## How the score works

Each pair goes through two stages:

### 1. Hard filters (dealbreakers)

A pair is discarded with a recorded reason if:

- they don't share the same **language**, or
- their **timezones** differ by more than 4 hours, or
- either one can commit fewer than **5 hours/week**.

### 2. Compatibility score

```
score = mean(personal_compatibility, need)
```

Both blocks are weighted sums in the 0–1 range:

**Personal compatibility** — *would we get along as people?*

| Trait | Weight |
|---|---|
| Risk appetite | 15% |
| Decision style (planned ↔ trial-and-error) | 15% |
| Time horizon (months without results) | 15% |
| Trust | 15% |
| Energy | 15% |
| Discipline | 15% |
| Creativity | 10% |

Plus a **vision-alignment adjustment** based on an objective-similarity matrix
(10 venture types, 45 pairwise similarity values): ≥ 60% similarity adds
+0.10, < 40% subtracts −0.50, anything in between is neutral.

**Need** — *does the other person cover what I'm missing?*

| Trait | Weight |
|---|---|
| Complementary skills (bidirectional: what I seek ∩ what you offer, both ways) | 35% |
| Shared sector (Jaccard) | 20% |
| Investment capacity similarity | 15% |
| Role-gap coverage (weighted by what each venture type typically needs) | 30% |

All weights, thresholds, the similarity matrix, and the needs-per-objective
map live in `config.json` — the scoring policy is data, not code.

## Project structure

```
zipzi/
├── matching.py        # Scoring engine: pairwise evaluation → resultados.csv
├── buscar_match.py    # Interactive CLI: build your profile, get ranked matches + breakdown
├── config.json        # Weights, objective-similarity matrix, needs-per-objective
├── perfiles.csv       # Sample dataset (15 synthetic profiles)
├── resultados.csv     # Sample engine output (regenerated by matching.py)
├── test_matching.py   # 34 pytest tests for the pure scoring functions
└── requirements.txt
```

## Quickstart

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Batch mode: score every pair in perfiles.csv → resultados.csv
python matching.py

# Interactive mode: answer the guided questionnaire, get your top matches
# with a per-trait breakdown of why each one fits
python buscar_match.py

# Test suite
pytest -v
```

and the weight it carried — so the score is always explainable.

## Metrics (sample dataset)

- **34/34 tests passing** (`pytest`), covering Jaccard, scale similarity,
  skill complementarity, hard filters, both score blocks, and edge cases
  (missing social traits in legacy profiles, unmapped objectives).
- **15 profiles → 105 pairs evaluated**; 47 pass the hard filters,
  58 rejected (57 language, 1 timezone).
- Score range on sample data: **0.00 – 0.557**; top pair
  Mateo Rossi × Lucas Fernández (personal 0.912, need 0.203).

## Roadmap

## Notes

- `perfiles.csv` contains **synthetic sample data** for demonstration.
- `resultados.csv` is regenerated every time `matching.py` runs.
- Profile lists accept both JSON (`["a","b"]`) and semicolon (`a;b`) formats.
